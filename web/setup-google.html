OWNER SETUP

Enable Continue with Google.

The game-side flow is ready. Google requires a client ID and secret saved privately in Supabase. A public publishable key cannot create these provider settings.

  1. Open Google Auth Platform. Select or create an Inside LASU project. Configure Branding with the app name and your support/developer email. Choose an External audience. For initial testing, add the Google accounts that will test sign-in as test users. Public players require the audience/publishing settings to allow them.
  2. Under Clients → Create client, choose Web application. Use this authorised JavaScript origin:https://trippletee20.github.ioUse this exact authorised redirect URI:https://mwuagoxsbsayftvmyitb.supabase.co/auth/v1/callbackSave the client. Keep its Client ID and Client secret private.
  3. Open Supabase → Authentication → Sign In / Providers. Open Google, enable it, paste the Client ID and Client secret into Supabase, and save. Do not send the secret to Codex or put it in the repository.
  4. Open Authentication → URL Configuration. Set Site URL to:https://trippletee20.github.io/INSIDELASU/Under Redirect URLs, add this exact URL and save:https://trippletee20.github.io/INSIDELASU/auth/callback.htmlThis return page also handles email confirmations and expired-link errors.
  5. Open the sign-in page below. Choose Continue with Google, then pick a public username. Test two accounts before inviting players. No engine download is needed to complete account sign-in.
